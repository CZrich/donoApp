# Mockups de AlimentoRed

Esta carpeta contiene los entregables visuales de la Fase 6. Los diseños representan el flujo principal aprobado: acceso, publicación, búsqueda, reserva, entrega e impacto.

## Contenido

```text
mocks/
├── wireframes/
│   └── flujo-principal.svg
└── mockups/
    ├── index.html
    ├── styles.css
    └── app.js
```

## Revisar los diseños

1. Abrir `wireframes/flujo-principal.svg` para revisar estructura y jerarquía.
2. Abrir `mockups/index.html` en un navegador para recorrer el prototipo visual.
3. Usar la barra superior del prototipo para cambiar de pantalla.
4. Probar los botones principales: iniciar sesión, publicar, reservar y confirmar entrega.

No se requiere instalar dependencias ni ejecutar un servidor para revisar el prototipo.

## Pantallas incluidas

1. Bienvenida e inicio de sesión.
2. Registro y selección de rol.
3. Inicio del donante.
4. Publicación de una donación.
5. Inicio de la organización social.
6. Listado y filtros.
7. Detalle y reserva.
8. Historial e impacto.
9. Perfil.

## Limitación

El prototipo demuestra navegación y diseño. No guarda información ni se conecta con Supabase; esa integración corresponde a la fase de desarrollo Flutter.
